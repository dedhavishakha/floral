# Image guide for the current products

These are the 30 products in the store now, with the file names to save their images under and a ready prompt for each.

## How to make the images (ChatGPT or Gemini)

1. Start a **new chat for each product**, so the garment stays the same across its photos.
2. Send the product's prompt below. Save the image as `<handle>_1.jpg`. This is the main image on product cards.
3. In the same chat, send:
   > Show this exact garment, with the same cut, fabric, color and details, worn by a model: one consistent female model in her late 20s, natural makeup, relaxed neutral expression, minimal styling. Same background and light, portrait 3:4.

   Save it as `<handle>_2.jpg`. This is the image that appears when someone hovers over a product card.
4. In the same chat, send:
   > Now show a close-up of the same garment's fabric texture and details, or its back view if that is more interesting. Same background and light, portrait 3:4.

   Save it as `<handle>_3.jpg`.
5. Put every image in one folder. Keep the file names exactly as written: the handle is how the upload finds the right product.

**Image shape:** keep every image portrait and the same shape. Gemini can make 3:4. ChatGPT makes 2:3; if you use ChatGPT, the theme's **Product image ratio** setting should change to **Tall 2:3**.

**Duplicates:** "3-Piece Loungewear Set" and "Beige Linen Blouse" each appear twice in the store with different handles. Make images for both, or tell me which copy to delete.
